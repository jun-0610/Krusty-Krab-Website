# Krusty Krab Website

基礎程式設計（一）期末個人專案

## 專案簡介

本專案為元智大學「基礎程式設計（一）」課程期末個人專案，以《海綿寶寶》中的蟹堡王餐廳為主題，設計並開發多頁式網站。

專案透過 HTML、CSS 及 JavaScript 建立網站架構，練習網頁排版、導覽列設計、圖片輪播及網頁互動功能的實作。

## 專案收穫
透過本專案，我學習如何使用 HTML 開發完網站，並了解網站架構規劃、介面設計與前端開發流程。

在開發過程中，也透過除錯與測試逐步解決版面配置及功能實作問題，提升程式設計與問題分析能力。
