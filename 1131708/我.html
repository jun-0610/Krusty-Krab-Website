網站技術與功能說明

輪播功能 (Carousel)

首頁運用 Bootstrap 5 輪播元件，展示餐廳熱門圖片（企業理念、菜單封面、全體員工照），並支援自動輪播與左右箭頭切換。

漢堡選單與導航 (Navbar & Hamburger)

響應式頂部導航列，在行動端自動折疊為漢堡選單，整合品牌首頁、下拉分類（企業理念、菜單、員工介紹）與會員登入按鈕。

Bootstrap 5 響應式框架

全站導入 Bootstrap 5 CSS 與 JavaScript 套件，實現流暢的網格排版（Grid System）與跨平台裝置最佳適配。

互動點餐系統 (JavaScript Menu)

菜單頁面支援即時多選餐點計算，自動統計品項清單與即時總金額，模擬線上點餐流程。

多元整合連結 (External & Mail Links)

串接 Google 地圖商家位置、電子郵件 mailto 即時回饋機制，以及完整站內頁面無縫串連。
